Architecture Overview                                                                                        
                                                                                                               
  Your NoahApp is a Cosmos SDK blockchain using the modern depinject pattern (v0.50+). This is dependency      
  injection - instead of manually wiring everything, you declare what you need and the framework provides it.  
                                                                                                               
  ---                                                                                                          
  The Two Core Files                                                                                           
                                                                                                               
  app.go - The Application                                                                                     
                                                                                                               
  app_config.go - The Module Configuration                                                                     
                                                                                                               
  ---                                                                                                          
  Key Components Explained                                                                                     
                                                                                                               
  1. The App Struct (app.go:55-82)                                                                             
                                                                                                               
  type NoahApp struct {                                                                                        
      *runtime.App              // Embeds BaseApp - the ABCI engine                                            
                                                                                                               
      // Keepers - state managers for each module                                                              
      AccountKeeper   authkeeper.AccountKeeper   // Manages accounts                                           
      BankKeeper      bankkeeper.BaseKeeper      // Handles token transfers                                    
      StakingKeeper   *stakingkeeper.Keeper      // Validator delegation                                       
      // ... more keepers                                                                                      
  }                                                                                                            
                                                                                                               
  Keepers are the core pattern in Cosmos SDK:                                                                  
  - Each module has a keeper that manages its state                                                            
  - Keepers read/write to the blockchain's key-value store                                                     
  - Keepers expose methods for transactions and queries                                                        
                                                                                                               
  2. Dependency Injection (app.go:106-178)                                                                     
                                                                                                               
  appConfig = depinject.Configs(                                                                               
      AppConfig,  // From app_config.go                                                                        
      depinject.Supply(appOpts, logger),                                                                       
  )                                                                                                            
                                                                                                               
  depinject.Inject(appConfig,                                                                                  
      &appBuilder,                                                                                             
      &app.AccountKeeper,                                                                                      
      &app.BankKeeper,                                                                                         
      // ... all keepers auto-wired                                                                            
  )                                                                                                            
                                                                                                               
  The SDK automatically creates and wires all keepers based on your module configuration.                      
                                                                                                               
  3. Module Lifecycle (app_config.go:94-147)                                                                   
                                                                                                               
  PreBlockers:   []string{"upgrade", "auth"}        // Before block processing                                 
  BeginBlockers: []string{"mint", "distribution"...} // Block start                                            
  EndBlockers:   []string{"bank", "gov", "staking"}  // Block end                                              
  InitGenesis:   []string{"auth", "bank"...}         // Genesis order                                          
  ┌───────────────┬───────────────┬─────────────────────────────────┐                                          
  │     Hook      │ When It Runs  │             Purpose             │                                          
  ├───────────────┼───────────────┼─────────────────────────────────┤                                          
  │ PreBlockers   │ Before any tx │ Upgrades, consensus params      │                                          
  ├───────────────┼───────────────┼─────────────────────────────────┤                                          
  │ BeginBlockers │ Block start   │ Mint tokens, distribute rewards │                                          
  ├───────────────┼───────────────┼─────────────────────────────────┤                                          
  │ EndBlockers   │ Block end     │ Finalize validator set          │                                          
  ├───────────────┼───────────────┼─────────────────────────────────┤                                          
  │ InitGenesis   │ Chain start   │ Initialize state from genesis   │                                          
  └───────────────┴───────────────┴─────────────────────────────────┘                                          
  4. Module Permissions (app_config.go:66-75)                                                                  
                                                                                                               
  moduleAccPerms = []*authmodulev1.ModuleAccountPermission{                                                    
      {Account: minttypes.ModuleName, Permissions: []string{authtypes.Minter}},                                
      {Account: stakingtypes.BondedPoolName, Permissions: []string{authtypes.Burner}},                         
  }                                                                                                            
                                                                                                               
  Special permissions:                                                                                         
  - Minter - Can create tokens (only mint module has this)                                                     
  - Burner - Can destroy tokens                                                                                
  - Staking - Can lock/unlock bonded tokens                                                                    
                                                                                                               
  5. AnteHandler (app.go:262-278)                                                                              
                                                                                                               
  The transaction gatekeeper - runs before every tx:                                                           
  ante.NewAnteHandler(ante.HandlerOptions{                                                                     
      AccountKeeper:   app.AccountKeeper,  // Check account exists                                             
      BankKeeper:      app.BankKeeper,     // Check balance for fees                                           
      SignModeHandler: txConfig.SignModeHandler(),  // Verify signature                                        
      FeegrantKeeper:  app.FeeGrantKeeper, // Allow fee grants                                                 
  })

  What Each Core Module Does                                                                                   
  ┌──────────────┬─────────────────────────────────┬────────────────────────────────────┐                      
  │    Module    │             Purpose             │         Your Customization         │                      
  ├──────────────┼─────────────────────────────────┼────────────────────────────────────┤                      
  │ auth         │ Accounts, addresses, signatures │ Change Bech32 prefix (line 175)    │                      
  ├──────────────┼─────────────────────────────────┼────────────────────────────────────┤                      
  │ bank         │ Token transfers, balances       │ Add custom token denoms            │                      
  ├──────────────┼─────────────────────────────────┼────────────────────────────────────┤                      
  │ staking      │ Validator delegation            │ Configure bonding time, validators │                      
  ├──────────────┼─────────────────────────────────┼────────────────────────────────────┤                      
  │ mint         │ Inflation, new token creation   │ Custom inflation curve             │                      
  ├──────────────┼─────────────────────────────────┼────────────────────────────────────┤                      
  │ distribution │ Reward distribution             │ Fee distribution rules             │                      
  ├──────────────┼─────────────────────────────────┼────────────────────────────────────┤                      
  │ gov          │ On-chain governance             │ Voting periods, thresholds         │                      
  ├──────────────┼─────────────────────────────────┼────────────────────────────────────┤                      
  │ slashing     │ Penalize bad validators         │ Downtime/double-sign penalties     │                      
  ├──────────────┼─────────────────────────────────┼────────────────────────────────────┤                      
  │ upgrade      │ Coordinate chain upgrades       │ Plan upgrade handlers              │                      
  └──────────────┴─────────────────────────────────┴────────────────────────────────────┘

  Building Your Own Blockchain - Step by Step                                                                  
                                                                                                               
  Step 1: Customize Your Chain Identity                                                                        
                                                                                                               
  In app_config.go:92:                                                                                         
  AppName: "NoahApp",  // Change to your name                                                                  
                                                                                                               
  In app_config.go:175:                                                                                        
  Bech32Prefix: "cosmos",  // Change to "noah"                                                                 
                                                                                                               
  In app_config.go:198-199:                                                                                    
  Bech32PrefixValidator: "noahvaloper",                                                                        
  Bech32PrefixConsensus: "noahvalcons",                                                                        
                                                                                                               
  Step 2: Create a Custom Module                                                                               
                                                                                                               
  Structure for x/yourmodule/:                                                                                 
  x/yourmodule/                                                                                                
  ├── keeper/                                                                                                  
  │   ├── keeper.go      # State management                                                                    
  │   ├── msg_server.go  # Handle transactions                                                                 
  │   └── query.go       # Handle queries                                                                      
  ├── types/                                                                                                   
  │   ├── keys.go        # Store keys                                                                          
  │   ├── msgs.go        # Message types                                                                       
  │   └── genesis.go     # Genesis state                                                                       
  ├── module.go          # Module registration                                                                 
  └── autocli.go         # CLI commands                                                                        
                                                                                                               
  Step 3: Define Your Keeper                                                                                   
                                                                                                               
  type Keeper struct {                                                                                         
      storeService store.KVStoreService                                                                        
      cdc          codec.BinaryCodec                                                                           
      authority    string  // Usually gov module                                                               
  }                                                                                                            
                                                                                                               
  func (k Keeper) SetData(ctx context.Context, key, value []byte) error {                                      
      store := k.storeService.OpenKVStore(ctx)                                                                 
      return store.Set(key, value)                                                                             
  }                                                                                                            
                                                                                                               
  Step 4: Register Your Module                                                                                 
                                                                                                               
  In app_config.go:                                                                                            
  1. Add import: _ "github.com/yourrepo/x/yourmodule"                                                          
  2. Add to ModuleConfig:                                                                                      
  {                                                                                                            
      Name:   yourmoduletypes.ModuleName,                                                                      
      Config: appconfig.WrapAny(&yourmodulev1.Module{}),                                                       
  },                                                                                                           
  3. Add to BeginBlockers, EndBlockers, InitGenesis as needed                                                  
                                                                                                               
  In app.go:                                                                                                   
  1. Add keeper field:                                                                                         
  YourModuleKeeper yourmodulekeeper.Keeper                                                                     
  2. Add to depinject.Inject:                                                                                  
  &app.YourModuleKeeper,
